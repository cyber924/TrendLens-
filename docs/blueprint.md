# **App Name**: TrendLens AI

## Core Features:

- AI Trend Analyzer: Analyze trend data (styles, keywords, categories) from Naver, Coupang, and Zigzag to identify top 5 trending keywords, materials and colors. Visualization tool for trends.
- AI Product Suggester: Suggest optimal products based on consumer reviews, popular keywords, and user's uploaded product data using an AI powered product recommendation engine. Upload data using CSV files.
- Interactive Insights Dashboard: Display an interactive dashboard summarizing popular product rankings per platform, sales trends by category, and comparisons against competitors. Visual tool that turns collected data into metrics.
- AI Marketing Assistant: Provide AI-driven recommendations for ad keywords and automate the creation of marketing content (SNS, email, blog posts) based on trending data as a marketing assistant tool.
- CSV Analysis Upload: Enable users to upload their product list in CSV format and automatically analyze trends and competitiveness using Firebase Storage and Functions.
- Email Authentication: Allow users to sign up and log in securely using Firebase Authentication.
- UI Design and Animation: Implement a clear, card-based UI focused on statistical visualization using Recharts or Chart.js. Enhance UX with scroll-based fade effects and interactions using Framer Motion.

## Style Guidelines:

- The application should use a light color scheme. The primary color should be a vibrant purple (#9370DB) to evoke creativity and insight, inspired by the analytic nature of the app. 
- The background color should be very light purple (#F0F0F8), almost white to ensure readability and a clean aesthetic. This value maintains the association to insight but provides a lighter base.
- The accent color should be a slightly darker blue (#6495ED), for highlights and calls to action. This maintains an analogous relationship with the primary color while creating noticeable contrast.
- Use 'Inter' (a sans-serif font) for both headings and body text to maintain a modern and neutral aesthetic that ensures readability and accessibility. The user requested this font as an option.
- Employ clean and minimalist icons that visually represent trends, products, sales, and marketing concepts. Ensure they are consistent in style and size.
- Implement a card-based layout for a clean and organized display of data and insights. Utilize white space effectively to prevent clutter and improve readability.
- Use subtle animations with Framer Motion to enhance user interaction, such as fade-in effects on scrolling and smooth transitions on data updates.
